<h1 align="center" style="font-weight: bold;">LinAlg: Matrix Calculator and Equations Solver. 💻</h1>


This is my project dedicated to the basic topic of linear algebra - operations on matrices and matrix equations. This is my attempt to automate many operations on matrices studied at university. My Python implementation covers topics such as:
1. Loops and conditional operators;
2. List Comprehension;
3. Working with`__init__`, `@staticmethod`, `@property`, operator overloading, inheritance);
4. Working with FastAPI;
5. Decorators and wrappers;

What you can do in `matrix.py`?
1. Find transposed, inversed, cofactor matrices;
2. Find the sum of matrices;
3. Multiply matrix by number or by another matrix, or by itself;

What you can do in `operations.py`?
1. Find the value of basic Matrix expressions with the help of Shunting yard algorithm for parsing arithmetical expressions;

How to work with repo?
1. Assuming, you have already installed Python, clone this repository.
2. `pip install -r requirements.txt`
3. `uvicorn main:app --reload`
4. Go to `http://127.0.0.1:8000/docs` to make a POST query, or make it using `curl http://127.0.0.1:8000/`
